# Дизайн-студия «Design.pro» — Django проект

Проект интернет-портала дизайн-студии «Design.pro» по оформлению интерьеров жилых помещений, разработанный в точном соответствии с техническим заданием (Демэкзамен / WorldSkills / Практическая работа).

## 🚀 Быстрый старт проекта

1. Перейдите в папку с проектом:
   ```bash
   cd C:\Users\fer\PycharmProjects\YP_Django_3\design_studio
   ```

2. Активируйте виртуальное окружение:
   - В Windows PowerShell:
     ```powershell
     ..\.venv\Scripts\Activate.ps1
     ```
   - В командной строке CMD:
     ```cmd
     ..\.venv\Scripts\activate.bat
     ```

3. Запустите сервер разработки на требуемом порту **8089**:
   ```bash
   python manage.py runserver 8089
   ```

4. Откройте в браузере:
   - Главная страница: [http://localhost:8089/](http://localhost:8089/)
   - Административная панель Django: [http://localhost:8089/superadmin](http://localhost:8089/superadmin)

## 📋 Соответствие требованиям Технического Задания

| Требование ТЗ | Реализация в проекте |
| :--- | :--- |
| **Порт и адреса** | Сервер запускается на `http://localhost:8089/`, админка доступна по `http://localhost:8089/superadmin` |
| **3 типа пользователей** | Гость (просмотр главной, вход, регистрация), Авторизованный (создание, просмотр, удаление заявок), Администратор (смена статуса, категории) |
| **Серверная валидация регистрации** | ФИО (только кириллица, дефис, пробелы), Логин (латиница и дефис, уникальный), Email (валидный формат), Пароли (совпадение), Чекбокс согласия на обработку ПДн (обязателен). Ошибочные поля подсвечиваются красным. |
| **Создание заявки** | Поля: Название, Описание, Категория, Фото помещения/плана. Разрешены только `jpg, jpeg, png, bmp`, размер до 2 Мб. Автоматический статус `Новая` и метка времени. |
| **Удаление заявки** | Защита: удалить можно ТОЛЬКО свою заявку и ТОЛЬКО со статусом `Новая`. Окно подтверждения перед удалением. |
| **Личный кабинет** | Вывод всех полей, сортировка по убыванию даты, удобная фильтрация по статусам (Все, Новые, В работе, Выполненные). |
| **Главная страница** | Счетчик заявок со статусом «Принято в работу», вывод не более 4 последних выполненных заявок. |
| **Смена статуса (Админ)** | «Новая» → «Принято в работу» (обязателен комментарий); «Новая» → «Выполнено» (обязательно изображение дизайна). Смена со статусов «В работе» и «Выполнено» заблокирована. |
| **Управление категориями** | Добавление и удаление категорий. При удалении категории каскадно удаляются все её заявки (`on_delete=models.CASCADE`). |
